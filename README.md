This project was made using Netbeans IDE and JDK18.
this project uses MySQL and Netbean ide java.
no ai was used in making this project.

THE main use of this project is to create a website where every one could save their favourite movies and see reviews of other people

basically this project is a reddit version of IMDB.
unlike IMDB here people can post their own review here.

SPECS USED IN MAKING THIS PROJECT-
1. 24 gb RAM
2. Ryzen 7 7435hs
3. Nvidia RTX 4060
   note- this project can even run on a low end PC.

what you need to run this-
1. Netbeans IDE
2. JDK 18
3. MySQL connector.

Languages used-
1. JAVA
2. JAVA Swing
